# Image Gallery

A responsive image gallery with interactive features.

## Setup
1. Clone the repository.
2. Place your images in the `images/` directory (name them `image1.jpg`, `image2.jpg`, etc.).
3. Open `index.html` in a browser.

## Usage
- Click thumbnails or use **←**/**→** buttons to navigate.
- Press **Left/Right Arrow** keys for keyboard navigation.
