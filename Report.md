# Image Gallery Report

## Features Implemented
1. **Responsive Layout**: Uses CSS Flexbox/Grid for responsiveness.
2. **Thumbnail Navigation**: Clickable thumbnails below the main image.
3. **Keyboard Navigation**: Left/Right arrow keys to navigate.
4. **Active State**: Highlight current thumbnail.
5. **Hover Effects**: Scale thumbnails on hover.

## Challenges
- Ensuring smooth transitions between images.
- Handling edge cases for first/last image navigation.
- Making the gallery mobile-friendly.

## Improvements
- Add image preloading for faster transitions.
- Implement swipe gestures for mobile devices.
- Add lazy loading for images.
